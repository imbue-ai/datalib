# Audit: security and engineering hygiene — 2026-11-03

A dated record, not reference. The audit read the tree at `44f7215c8` and
the repository's GitHub settings on 2026-11-03. **Re-checked 2026-11-27
at `ee03cb1b1`: 25 findings open, below; the rest fixed or tracked
elsewhere.** Each open finding was read again in the code on that day and
its paths and line numbers moved to match; none was run again. Read the
code before repeating one as current. The threats themselves, and what is
open about each by decision, are in
[`security_posture.md`](../security_posture.md).

The 2026-11-03 read was six read-only passes: dependencies and supply
chain; SQL construction; HTML injection and the browser-side trust
boundary; the HTTP server, applets and desktop shell; untrusted input on
the ingest side; copy-paste and rule drift. It is a blameless review: it
says what the tree does, not who wrote it.

## Still open

Paths are under `datalib/`, with `etl/` short for `backend/etl/`;
`.devcontainer/` and `docs/` are at the repository root. All Low.

**Server and desktop shell**

1. **Every remote capability allows any port.** Seven files in
   `tauri/capabilities/` grant `http://127.0.0.1:*/**` and
   `http://localhost:*/**`. #1616 tried granting only the open library's
   server and reverted it: the navigation rule (#1548) already keeps
   another port's page out of the app's windows, and a misspelt
   permission granted at runtime would go unnoticed until a release.
2. **`GET /api/config` returns the whole file** (`get_config`,
   `backend/http/src/lib.rs:945`). The one secret a config holds today is
   YoLink's `family_device_id` and `device_udid`, which together let
   anyone fetch a device's history
   (`etl/providers/yolink_config/src/lib.rs:35-69`). The route needs the
   token and answers this site alone.
3. **A refused request is logged at info, from outside the token gate**
   (`request_log::record`, layered outside `auth::require_token` at
   `backend/http/src/lib.rs:340-343`; `worth` in `request_log.rs:66-72`).
   Any web page can add lines to the log.
4. **The 401 page names the token file**, so a stale tab or a link from
   another site shows the data root's path (`unauthorized`,
   `backend/http/src/auth.rs:442-472`).

**Ingest**

5. **My Maps KML recurses with no depth limit.** #1626 capped its size
   (256 MiB), and the parse is a loop, but `collect` and `Node::into_json`
   (`etl/providers/google_takeout/src/ingest/my_maps.rs:103-148,180-207`)
   recurse once per nested `<Folder>` or element. A deep enough file
   overflows the stack, which kills the process.
6. **`backend/whatsapp-backup/src/header.rs:66,121` add a 64-bit varint
   length unchecked**, so a crafted `.crypt15` header panics.
7. **Table names minted from export file names go into SQL unquoted.**
   `table_name` (`etl/files/src/export_files.rs:22`) keeps only
   alphanumerics and `_`, so nothing injects, but `Order.csv` becomes
   `order`, a keyword, and fails the whole ingest, and `problems.csv`
   lands in the store's own `problems` table. The statements are in
   LinkedIn's `write_table`
   (`etl/providers/linkedin/src/ingest/mod.rs:264-300`) and Facebook's
   `upsert_and_prune` (`etl/providers/facebook/src/ingest/mod.rs:320-392`).
8. **Free-text `LIKE` has no `ESCAPE`**
   (`backend/unified_grid_and_search_index/src/db.rs:178-187`), so `%`
   and `_` typed into a search are wildcards. It is bound, not
   injectable. The name, value and grouping searches beside it do
   escape.
9. **Email handles fold with Unicode `to_lowercase()`**
   (`backend/handle/src/lib.rs:127`): the Kelvin sign becomes `k`, so two
   spellings become one handle.
10. **Notion's `markdown_lite` builds `<a href>` with no scheme check**
    (`etl/providers/notion_render/src/render/enhanced.rs:492-511`). The
    UI's sanitizer catches `javascript:`, so this is defence in depth.
11. **The SQLite mirror ATTACHes its source read-write**
    (`etl/sqlite_mirror/src/mirror.rs:323-336`). With `snapshot` on, the
    default for Lightroom, Apple Photos and Apple Messages, that is the
    `VACUUM INTO` copy; a config that turns it off attaches the live
    catalog or library.

**Supply chain**

12. **latchkey loads every directory under its `plugins/`.** Read in
    latchkey 3.21.0's `dist/src/plugins.js` on 2026-11-03; not re-read
    in 3.25.0, today's pin. Datalib writes only its own stamped plugin
    (`backend/http/src/plugins.rs`) and leaves any other alone.
13. **Base images by tag:** `ubuntu:26.04` in `docker/Dockerfile:64` and
    `.devcontainer/Dockerfile:35,42`. The CI image installs latchkey with
    `npm install -g "latchkey@${LATCHKEY_VERSION}"`
    (`.devcontainer/Dockerfile:94`): the version is pinned, its
    dependencies are not locked.
14. **Dependabot has no `cooldown`**, so the desktop app's crates and the
    npm trees skip the 7-day burn-in (`security_posture.md`, the guards
    table).
15. **`docs/dev/doltlite_codelab.md:17` installs doltlite with
    `sudo bash -c 'curl … releases/latest/… | bash'`.**
