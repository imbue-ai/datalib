# Audit: the reference docs against the tree, 2026-11-18

This is a record, not reference. It read every reference doc (the doc map's
docs, and the `README.md`, `INGEST.md` and `TRANSLATE.md` files beside the
code: 132 files, about 41,000 lines) against the tree at `301359c0`, using
the procedure in [`style.md`](../style.md) §"Auditing the tree for drift and
repetition". It started from the merged PR descriptions of Oct 25 – Nov 18
(about 430 PRs), since those say what moved. In that window qmd was removed,
the index step was renamed and absorbed the keyword index and the
aggregator, problems moved into the step that finds them, and the build
moved to a hermetic toolchain. Plans and audits were not touched.

**How far to trust it.** The docs were split by area among nine readers,
with no file shared. Each grepped every name a doc gives (path, type,
function, table, key, flag, target) and fixed or cut what was not there.
Behaviour was read in the code where a claim mattered; it was not run.
Nothing that needs a real library, a doltlite shell or a live account was
checked; those claims are listed under "Not verified" below. The docs that
are compiled into `datalib-step help`, and the config examples, were
checked by their tests after the edits (`datalib_agent_docs_unittests`,
`datalib_step_unittests`, `http_unittests`, `//:lint_repo`), which caught
a compiled-in doc citing a file a reader without the repo cannot open,
and an example config edited in place of the stanzas it is generated
from. The Docker page's `doc_test`, which needs a Docker daemon, was not
run.

## What was fixed

About 90 files changed, 1,170 lines out and 980 in. Grouped by kind:

- **Names that were gone.** These include the per-provider `*-ingest`
  binaries and their flags (email, Claude, GitHub, GitLab),
  `MigrateState` (now `PassState`), `insert_grid_row`,
  `needs_reading_by_path`, `processor::plan_render`, `to_payload`,
  `markdown_html_as_typed`, `deleted_upstream_at`, `RUST_TEST_THREADS` in
  the applet tests, the qmd search flag on `GridRow`, log lines the sync
  audit looked for, and test targets that never existed.
- **Behaviour that changed.**
  - Problems are no longer copied by render or by the index (#1766).
  - A new source needs no edit to the index's `inputs`, because the
    index reads `*/render_markdown` (#1811).
  - The grid index is plain SQLite.
  - Since doltlite 0.51.12, a plain file's WAL is checkpointed
    automatically (it still keeps its size).
  - The e2e suite is three parts, each in its own job.
  - The release ships a CUDA module, a `-cuda` image and attestations.
  - Media seals only at the end, so an interrupted scan keeps its hashes
    but not its batches.
  - Claude's text before a tool call is its own item.
  - The `embedder` lock no longer rests on anything qmd did.
- **Counts.**
  - Providers that scan files through `file_changes_scan`: fourteen.
  - Providers that mirror a SQLite file: five.
  - Warnings the loader gives: more than "four".
  - Config rewrites: fourteen.
  - Facebook: fourteen tables.
  - `DownloadRun` is used by 12 of 32 source types.
  - The http test slices: six.
- **Tables.**
  - The method table now matches `ingestMethods.json`.
  - The time-window table gains Calendly and Baby Connect.
  - "Who writes a handle" and "who draws a chip" gain Todoist,
    Baby Connect, Notion mentions, Google Drive and email mentions.
- **Repetition cut to a link.**
  - AGENTS.md: about 70 lines of detail went to the docs that hold it
    (the config's kinds of entry, the doltlite test targets, store owners,
    precommit flags, the RunProblems plumbing, RFC 9557,
    `file_changes_scan`'s mechanics).
  - JSONB now has one home, `etl/README.md`.
  - The search keys have one home, `docs/user/searching.md`, which
    `agent_user.md` and `contacts.md` now point to.
  - Chip marking and trust live in `chips.md`.
  - `ci.md`'s write-key section points to `security_posture.md`.
  - The release skill points to `release_steps.md`.
  - `doltlite.md`'s copy of the reader package's page is cut.
  - Rules that providers' notes repeated now link to their homes:
    latchkey curl, owed records, the `since` grammar, volatile fields,
    the cost of one transaction, and the file-scan rules. The file-scan
    rules were the largest exact repeat in the tree, 55 words in both
    media and pdf.
  - `find_repeats.py` at 14 words went from 130 findings to 113. Most of
    the rest are deliberate:
    - the two agent guides, each served alone with no token;
    - per-type sections of `getting_your_data.md`, which
      `help <type>` prints alone;
    - identical one-line pointers.
- **History cut** from reference docs: "used to", "before #NNN", "now", and
  version-pinned phrasings that were no longer the pin.

Four code comments that said something false were corrected: `grid_index::close_index`, `manage/problems.rs`'s header,
`datalib/ui/BUILD.bazel`'s e2e comment, and the two Dockerfiles' Ubuntu
version.

## Still open

- **`chipDragQuery` and a document.** `ui/src/cards/chipActions.ts` says no
  search key names a document, so a document chip drags as a link. Since
  #1825 `datalib_document_id:` does name one (`chips.md` now says so).
  Dragging a document chip could write that search.
- **`portable_search.rs` still reserves the `qmd` and `qmd_vsearch` keys**
  (`etl/macros/src/portable_search.rs`). Check whether anything still
  needs them.
- **The plain-curl rules have no home but AGENTS.md** §"Auth (web API)":
  `HttpRequest::plain`, no `~/.curlrc`, https only, `max_bytes`. They
  belong in `latchkey.md` or a README beside `etl/web/`.
- **`docs/dev/fastmail.md`** is accurate but not on the doc map. It covers
  the credentials for Fastmail's email, calendar and contacts, so it reads
  as a section of `latchkey.md`.
- **`etl/sqlite_mirror/` has no README.** Five providers use the engine,
  and `lightroom/INGEST.md` is its de facto home.
- **`claude/INGEST.md` §"Bootstrapping from an export"** describes
  something not built. It may belong in a plan.
- **`chat-common/README.md` §"Plain text is escaped"** still partly
  repeats `data_architecture_parse_and_render.md` §"Upstream text is
  escaped".

## Not verified

The following claims were left in place:

- Measured numbers: times, sizes, rates and counts on real catalogs. This
  includes CPU embedding speed in `first_time_user.md` and the Docker
  page; `logging.md`'s p95 times; `step_protocol.md`'s 2.9 GB;
  `parse_and_render.md` §"Memory"; the four real Lightroom catalogs; the
  Modal and Metal figures in `embedder/README.md`; and AGENTS.md's
  test-loop timings.
- Facts that need a binary or an account this read did not have:
  - every output in `doltlite_codelab.md`;
  - `doltlite_chunk_walk.c` (in the fetched amalgamation);
  - the umap-rs optimiser internals;
  - Garmin's `login --domain garmin.cn`;
  - Codex's version shapes;
  - the latchkey 3.15/3.16 measurements in `fastmail.md`;
  - the curl-impersonate default profile;
  - the Xcode and SDK versions on `macos-26`;
  - the cloud environment's host allowlist;
  - the external `datalib-hello` package.
- AGENTS.md's "84 at the last count" for the `rdeps` query.
- Several claims whose path through the code was not traced:
  - a turned-off source leaving the search index after an upgrade
    (`searching.md`);
  - `me` refused by name on an old index (`contacts.md`);
  - the grey Manage count (`problem_mutes/README.md`);
  - `DATALIB_TOKEN` pinning the token (`agent_user.md`).
