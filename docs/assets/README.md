# docs/assets

Images the docs use and the app does not. The README's source grid
takes its brand marks from `datalib/ui/src/assets/` (one source of
truth, shared with the Manage screen); what lives here is only the
white-on-dark twins of the three solid-black marks (Garmin, GitHub, Notion), for GitHub's dark theme,
and the glyph for the "your own source" cell. Glyphs are Material
Design Icons (Apache-2.0).
