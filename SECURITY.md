# Reporting a security problem

Please report it privately: open the repository's
[**Security** tab](https://github.com/imbue-ai/datalib/security) and choose
**Report a vulnerability**. Please don't open a public issue, because datalib
holds people's email, messages and sign-ins.

It helps to say which version you ran (`datalib-dag --version`), what you did,
and what an attacker would gain. Please use made-up data, not anything from a
real person's library.

We fix the latest release, so check that the problem is still there before
reporting it.

[`docs/dev/security_posture.md`](docs/dev/security_posture.md) says who we guard
against, what stops them, and what is still open. Something listed there as open
is known, but tell us if you have shown it can be done.
